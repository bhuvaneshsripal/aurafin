Put index logo images here (PNG, square or near-square, ~96x96 or larger, transparent or white background).

  nse.png   - shown for every NSE index
  bse.png   - shown for every BSE index

Optional, to give one index its own logo, name the file after its key:
  nifty50.png, niftybank.png, sensex.png, bankex.png, midcapselect.png, niftypharma.png, niftyit.png ...
(keys are in api/_lib/indianIndices.js)

A per-index file wins over the exchange logo. Missing files fall back to a generic icon.
