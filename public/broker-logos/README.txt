Broker logos shown on the Import page.

Run   npm run logos   (needs internet) to download every broker's own logo into this folder.
Files here are used first. Add --force to re-download:   npm run logos -- --force

To set one by hand, save a square PNG (or SVG) named after the broker key:
  zerodha groww indmoney upstox icici cdsl angelone aionion chola mstock 5paisa vested tickertape stockal ibkr kuvera mfcentral

Anything missing falls back to the website icon, then to a coloured initial.
